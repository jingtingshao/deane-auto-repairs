# Service checklist — aligned to website prices

Matches `index.html` `#prices` comparison table and `data/checklist.js`.

| Package | Website price | Report package value |
|---------|---------------|----------------------|
| Standard Service | $199 | `standard` |
| Premium Service | $299 | `premium` |
| Diesel / 4WD Service | $299 | `premium` checklist (+ diesel job type) |
| European Service | $299 | `premium` checklist (+ european job type) |
| WOF | $79 | job type `wof` (official result panel) |

Legacy values `full` / `full_service` still load as **Premium**.

Oil & filter change, top-ups and service light reset are **Work completed** ticks, not checklist items.

## Included on both Standard & Premium

- Brake fluid level; coolant, power steering and washer fluid levels  
- Air filter; engine / transmission oil leak inspection  
- Battery test, drive belts, exterior lights & indicators, dashboard warning lights, wiper blades  
- Brake inspection (**wheels on**) - pads & disc visually check; brake warning / ABS lights  
- Tyre pressures set & tyre condition inspected  
- Steering system, including rack & linkages  
- Exhaust system  

## Premium only ($299 package)

- Brake fluid condition; radiator cap & hoses (cooling system)  
- Transmission / gearbox fluid; differential fluid (level, where applicable)  
- Brake inspection (**wheels off**) + pad / disc / lines / parking brake detail lines  
- Suspension components, wheel bearings  
- Road test up to 50 km/h  

Statuses: **OK** · **Watch** · **Attention** · **N/A**
